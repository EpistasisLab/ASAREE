What ran and why
  • Binary outcomes are analyzed with a binomial model.
  • Selected model: binomial. Factors: Approach, Setting. Interactions included through order 2.
  • Comparisons are equally weighted differences or ratios of predicted means; 95% confidence intervals.
  • Factor tests evaluate model terms; comparisons evaluate predicted overall means. These can answer different questions for nonlinear or multipart models.
  • Differences subtract the second listed condition from the first; ratios divide the first by the second. The null value is 0 for differences and 1 for ratios. Interactions compare effects across settings.
  • Holm correction is applied across factor tests and within each factor's comparison family. Separate metrics are not corrected together; cross-metric findings are exploratory.
  • Analytic and permutation results are reported independently; neither is selected based on significance.
  • Permutation p-values are separately Holm-adjusted working-scale OLS sensitivity checks, not permutations of the model's Wald statistic. Labels are exchanged within other-factor strata for main effects; interactions use approximate Freedman–Lane reduced-model residual permutation. These require exchangeability under the tested null, beyond independent runs. Nonlinear/multipart models and rank-based ordinal checks may test different null hypotheses; agreement is descriptive, not proof of validity.
  • Analytic and bootstrap intervals are pointwise 95% intervals, not multiplicity-adjusted. Their agreement compares whether they include the null; it is not a comparison with the Holm-adjusted p-value.
  • Bootstrap — Cell-stratified case bootstrap; fixed selected model; percentile intervals: 1000 requested, 1000 attempted, 1000 successful, 0 failed. Status: completed. Intervals require completion and at least 90% successful refits. The selected family is held fixed; model-selection uncertainty is not included.
  • Permutation — Approach: 1999 requested, 1999 completed; labels permuted within strata of Setting; working scale: response. Monte Carlo p-value uses (exceedances + 1)/(permutations + 1); minimum 0.0005.
  • Permutation — Setting: 1999 requested, 1999 completed; labels permuted within strata of Approach; working scale: response. Monte Carlo p-value uses (exceedances + 1)/(permutations + 1); minimum 0.0005.
  • Permutation — Approach:Setting: 1999 requested, 0 completed; Permutation withheld; working scale: response. Interaction permutation unavailable: exchangeable additive errors are not established for this non-Gaussian model.
  • Comparisons — Delta-method Wald z-test (HC0 robust covariance): Checks whether the difference between conditions changes across the other factor (null interaction = 0).
  • Comparisons — Delta-method Wald z-test (HC0 robust covariance): Checks whether the first condition's predicted average differs from the second (null difference = 0).
  • Factor tests — Wald chi-square test (HC0 robust covariance): Checks whether the effect of one factor depends on the others in this interaction.
  • Factor tests — Wald chi-square test (HC0 robust covariance): Checks whether this factor contributes to the fitted model after accounting for other included terms.
  • Confidence intervals — Delta-method confidence interval: Approximates uncertainty in the predicted comparison using the fitted parameter covariance.
  • String conversion: 'yes' → 1, 'no' → 0
